# 🌍 Travel Guide Assistant

A web-based **Travel Guide Assistant** built using Python and Streamlit that helps users explore travel destinations, get recommendations, and plan trips through an interactive and user-friendly interface.

---

## Features

-  Explore travel destinations easily  
-  Get travel recommendations  
-  Simple and interactive UI  
-  Clean Streamlit-based design  
-  Fast and lightweight web app  
-  Easy to extend with APIs (weather, maps, etc.)

---

## Tech Stack

- Python   
- Streamlit   
- Git & GitHub
